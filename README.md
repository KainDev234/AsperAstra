# AsperAstra

Minimalistisches Weltraum-Aufbauspiel fürs Handy, in dem die Lichtgeschwindigkeit zählt. Im Browser spielbar, ohne Datenübertragung.

- Konzept: [KONZEPT.md](KONZEPT.md)
- Spielen: https://kaindev234.github.io/AsperAstra/ (Stand von `main`)
- Lokal starten: `node server.js`, dann http://localhost:8080 öffnen
- Tests: `node tools/test.mjs`
